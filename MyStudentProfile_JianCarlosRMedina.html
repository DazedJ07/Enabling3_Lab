03HTML LEARNING NOTES

A few things
about HTML.

Answers to the guide questions from my HTML activity.

01What is the purpose of <!DOCTYPE html>?
It tells the browser that the document uses modern HTML5, so the page is rendered according to current web standards.
02What information is placed inside the <head> element?
The head contains page information such as the title, character encoding, viewport settings, and metadata. It is not the main visible page content.
03What is the function of the <body> element?
The body contains the webpage content visitors see and interact with, including headings, paragraphs, links, lists, and images.
04What content is usually placed inside the <header> element?
A header usually introduces a page or section. It can contain a title, logo, introductory text, or other introductory content.
05What is the purpose of the <nav> element?
The nav element groups important navigation links, helping visitors move to other pages or sections of the current page.
06Why is the <main> element used?
Main identifies the page’s primary content. A page should generally have one main element, separate from repeated navigation, headers, and footers.
07What is the difference between <section> and <footer>?
A section groups related content, usually around a shared topic and heading. A footer contains closing or supplementary information for its page or section, such as authorship or contact details.
08What happens when a user clicks the “About” link in the sample webpage?
The link’s href="#about" takes the browser to the element with id="about", scrolling the page to that section.
